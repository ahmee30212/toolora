# Toolora

Free Online Tools for Everyone.

A fast, accessible, privacy-conscious collection of practical browser-based tools.

## Stack

- Astro + TypeScript
- React islands for interactive workspaces
- Tailwind CSS
- Lucide icons
- Vitest for unit tests
- Cloudflare Pages for static deployment

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
